# Security

DHI Orbit listens on loopback only and reads files on your machine. See "Security model" in the README for what it can and cannot do.

Report a vulnerability privately through GitHub: <https://github.com/Dv04/dhi-orbit/security/advisories/new>. Please do not open a public issue for it. You get a reply within a few days; fixes ship in the next patch release and are credited in the changelog unless you prefer otherwise.

Supported versions: the latest release on PyPI.
